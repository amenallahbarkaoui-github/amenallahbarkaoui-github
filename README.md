## About Me

My interests lie at the intersection of cybersecurity,
artificial intelligence and software engineering, with a
particular focus on **Agentic Cybersecurity**.

I explore how autonomous AI agents, intelligent automation
and security research can improve vulnerability discovery,
security assessment and the development of resilient
software systems.

Alongside cybersecurity, I develop backend services,
web applications and native Android solutions, with an
emphasis on security, reliability and maintainability.

## Research & Technical Focus

| Domain | Areas of Interest |
| :--- | :--- |
| **Agentic Cybersecurity** | Autonomous security agents, multi-agent architectures, AI-assisted security assessments |
| **Offensive Security** | Authorized penetration testing, vulnerability research, web and API security |
| **AI Security** | LLM security, prompt injection, agent trust boundaries and secure tool execution |
| **Backend Engineering** | API architecture, authentication, scalable services and database systems |
| **Software Engineering** | Web development, native Android applications and secure software design |

## Current Focus

- AI-driven offensive security methodologies.
- Autonomous and multi-agent security systems.
- Vulnerability discovery and evidence-based validation.
- Secure agent orchestration and controlled tool execution.
- Security automation and intelligent testing workflows.
- Reliable backend architectures and secure API design.
